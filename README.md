Hotel Reservation System

Project Overview

The Hotel Reservation System is a Java-based console application developed as part of the CodeAlpha Internship.

This project helps users manage hotel room reservations through a simple menu-driven interface.

Features

- View available rooms
- Book a hotel room
- View booking details
- Cancel reservations
- Calculate total booking cost
- Exit the application

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Visual Studio Code

How to Run the Project

1. Install Java JDK.
2. Open the project folder in Visual Studio Code.
3. Open "HotelReservationSystem.java".
4. Run the Java program.
5. Follow the menu options displayed in the terminal.
